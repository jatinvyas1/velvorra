# Velvorra International — Angular Website

Modern Angular 17 (standalone components) site for **Velvorra International**, a Trusted Global Agro Trade Partner.

## Quick start

```bash
npm install
npm start
```

Then open http://localhost:4200

## Build

```bash
npm run build
```

Output goes to `dist/velvorra`.

## Stack

- Angular 17 (standalone components, signals)
- SCSS with custom design tokens
- Angular animations + IntersectionObserver scroll reveal
- Reactive Forms
- No external UI library — fully custom

## Pages

- `/` Home — hero, value props, featured products, global reach
- `/products` — full catalog of 7 commodities
- `/about` — company story
- `/contact` — form + business details + map
